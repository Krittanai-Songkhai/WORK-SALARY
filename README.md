# Work Desk — ส่งงาน / เบิกผลงาน ชุดช่าง (แรง DC บริษัท และ ผรม.)

เว็บแอปแยกจาก Inspection Desk (ไม่ต้องมีขั้นตอน build) ใช้ `config.js` ชุดเดียวกัน → โปรเจกต์ Supabase เดิม
ไม่ต้องรัน SQL เพิ่ม: เก็บในตาราง `docs` เดิม (collection ขึ้นต้น `wd_`, กลุ่ม `wd`, สิทธิ์ “เฉพาะสมาชิกที่ล็อกอิน”)

## ใช้งาน
1. **ตั้งค่า** → ใส่ชื่อโครงการ/ผู้ว่าจ้าง/หมวดงาน/อาคาร (ค่าเริ่มต้น D, E, F&J, G และชุดช่างตามรายชื่อที่ให้มา)
2. **BOQ** → นำเข้า Excel (เลือกคอลัมน์ รายการ/หน่วย/ปริมาณ/ค่าแรง) หรือกรอกเอง
3. **ตารางห้อง** → นำเข้า Excel (หนึ่งแถว = หนึ่งห้อง, หัวคอลัมน์ = ชื่อ ITEM, ค่า = ตร.ม.) หรือกรอกเอง; ผลรวมเทียบ BOQ ใต้ตาราง
4. **ชุดช่าง** แต่ละชุดเลือกรูปแบบเอกสาร
   - *รายการงาน*: ตารางเบิกผลงานแบบ Excel (ปริมาณ × ค่าแรง, งวดก่อน/งวดนี้/สะสม/%/หมายเหตุ) แต่ละรายการเลือก “BOQ ที่คลุม”; ถ้าไม่มี BOQ ระบบเขียนหมายเหตุ “ไม่มี BOQ คลุม” ให้ในเอกสาร
   - *ตารางห้อง*: เลือก ITEM + ค่าแรง/ตร.ม. และห้องที่ชุดรับผิดชอบ; เอกสารเป็นตารางห้อง × ITEM พร้อม ตร.ม. และหน้าสรุปงบเทียบ BOQ
5. กด **เริ่มงวดใหม่** → กรอกปริมาณที่ทำเสร็จ “ในงวดนี้” (มีปุ่มลัด +25% / +50% / เสร็จ / เสร็จทั้งห้อง) → **ดูเอกสาร / PDF / Excel**
6. **ภาพรวม** → ยอดสัญญา/เบิกสะสม/% ทุกชุด, ปุ่ม “สรุป PDF” เป็นใบปะหน้ารวมทั้งอาคาร

## ข้อมูล
- บันทึกในเครื่องทันที (ใช้ออฟไลน์ได้หลังเปิดหน้าเว็บแล้ว) และซิงก์ขึ้น Supabase เมื่อล็อกอิน; มีไฟล์สำรอง JSON ในหน้า ตั้งค่า
- ซิงก์แบบ “คนล่าสุดชนะ” ต่อ 1 รายการ (ชุด/รายการ BOQ/ห้อง/งวด) — คนที่ไม่ใช่เจ้าของต้องได้รับสิทธิ์ผู้แก้ไขในหน้า ตั้งค่า

## โครงไฟล์
`js/store.js` ข้อมูล+ซิงก์ · `js/calc.js` คำนวณ/ข้อมูลเริ่มต้น · `js/docs.js` เอกสาร PDF/HTML/Excel · `js/imp.js` นำเข้า Excel · `js/views.js` หน้าจอ · `js/app.js` ปุ่ม/อีเวนต์

## เพิ่มเติม (รอบ 2)
- **ส่งออกแยกชุด:** หน้าภาพรวมมีปุ่ม PDF ต่อชุด และ “ส่งออกแยกชุด (ZIP)” เลือกชุด/รูปแบบ (PDF, Excel) ได้ ไฟล์ละหนึ่งชุด (ใช้งวดล่าสุด)
- **แบบ + รูป เหมือน Inspection:** แท็บ “แบบ” อัปโหลด PDF/รูปเข้าคลังต่ออาคาร (PDF แยกหน้า) → ในแต่ละงวดกด “เลือกแบบจากคลัง” แล้ววาดทับ/ระบายสี/ใส่ข้อความได้ (แยกต่องวด), “รูปถ่ายประกอบ” ถ่าย/อัปโหลด + คำอธิบาย + ลูกศร/ข้อความ — ต่อท้ายเอกสารของชุดอัตโนมัติ
- **โลโก้:** ตั้งค่า → โลโก้บริษัท แสดงมุมซ้ายของเอกสารทุกใบและแถบด้านบน
- รูปเก็บในเครื่อง (IndexedDB) และอัปโหลดขึ้น bucket เดิม `inspection-images` (ชื่อไฟล์ขึ้นต้น `wd-`) เมื่อล็อกอิน; ไฟล์สำรอง JSON ไม่รวมรูป

## นำเข้า BOQ จาก Excel หลายชีต
แท็บ BOQ → “นำเข้า Excel”: เลือกไฟล์ → ระบบจับคู่ชีตกับอาคารจากชื่อชีต (เช่น `D`, `อาคาร E`, `F&J`; ชีตที่ไม่ตรงจะข้าม) ตรวจคอลัมน์ให้เอง (รหัสหัวข้อ 1 / 1.1, รายการที่ขึ้นต้น “-”, ตำแหน่ง ผนังใน/นอก, หน่วย, ปริมาณ, ค่าแรง, BOQ และ 80%) แก้คอลัมน์ได้ต่อชีตก่อนกดนำเข้า
รายการที่ใช้ BOQ ตัวเดียวกัน (หมวด/หน่วย/ปริมาณ BOQ เท่ากัน เช่น ผนังใน+ผนังนอก) จะรวมปริมาณเทียบเพดาน 80% และแสดง “เกิน 80% BOQ”

## รายการอื่นๆ นอกตารางห้อง / หมายเหตุรายการไม่มี BOQ
- ชุดแบบ “ตารางห้อง” มีกล่อง **รายการอื่นๆ นอกตารางห้อง** (เช่น ปูกระเบื้องทางเดินชั้น 1) เพิ่มเองหรือ “เพิ่มจาก BOQ” ได้ เบิกรวมงวดเดียวกับตารางห้อง
- รายการที่ไม่มี BOQ เลือกหมายเหตุได้: **ไม่มี BOQ คลุม** (ค่าเริ่มต้น) / **งานเพิ่ม** / **ไม่ใส่หมายเหตุ**
- ใน PDF/Excel รายการอื่นๆ จะแยกหน้า/ชีตของตัวเอง และรวมอยู่ในหน้าสรุปงบและยอดรวมเบิก

## ซิงก์ PC ↔ มือถือ
- ต้อง **เข้าสู่ระบบด้วยบัญชีเดียวกันทั้งสองเครื่อง** (ป้ายมุมขวาบนต้องเป็น “ซิงก์แล้ว ↻”) ถ้าเป็น “ในเครื่องนี้ · ยังไม่ซิงก์” แปลว่าข้อมูลอยู่เฉพาะเครื่องนั้น กดป้ายเพื่อเข้าสู่ระบบ
- ดึงข้อมูลใหม่อัตโนมัติทุก 20 วินาที / เมื่อสลับกลับมาที่แอป (ถ้าไม่ได้กำลังพิมพ์) กดป้ายเพื่อซิงก์ทันที
- เครื่องที่เพิ่งล็อกอินครั้งแรก ข้อมูลบนระบบ (cloud) ชนะข้อมูลตัวอย่างในเครื่อง

## ใส่ % ตอนกรอกงวด / กรอกตารางห้องเร็วขึ้น
- หน้าบันทึกปริมาณงวด: ช่อง **% งวดนี้** ต่อรายการ (พิมพ์ % ของปริมาณสัญญา → ปริมาณคำนวณให้ / พิมพ์ปริมาณ → % ปรับตาม) ในตารางห้องมีช่อง % ต่อห้อง ต่อชั้น และทุกห้อง
- แท็บตารางห้อง: **＋ หลายห้อง/หลายชั้น** (สร้างทุกชั้นพร้อมกัน ใช้ {F} แทนเลขชั้น), **⧉ คัดลอกชั้น** (ชั้น 1 → 2-7), และวางช่วงเซลล์จาก Excel ลงตารางได้โดยตรง

## หน้า BOQ แยกอาคาร → หมวดงาน
- เลือกอาคารด้วยปุ่มด้านบน แล้วเลือกหมวดงาน (หรือ “ทุกหมวด”) รายการแสดงเป็นกลุ่ม ย่อ/ขยายได้ แต่ละหมวดมีสรุป (จำนวนรายการ, มูลค่า, เกิน BOQ, ไม่มี BOQ)
- ＋ หมวดงาน / ＋ รายการ (ในหมวด) / เปลี่ยนชื่อหมวด / ย้ายรายการโดยแก้ช่อง “หมวด” ท้ายแถว / ค้นหา
- ลำดับหมวดและรายการเรียงตามลำดับในไฟล์ BOQ ที่นำเข้า; ตัวเลือก BOQ ในหน้าชุดช่างและหน้าต่าง “เพิ่มจาก BOQ” จัดกลุ่มตามหมวดด้วย

## นำเข้า BOQ รูปแบบ “ตารางแสดงรายการก่อสร้าง” (ไฟล์ KMIT ตึก D)
เลือก BOQ → นำเข้า Excel ระบบตรวจรูปแบบเองและแยกให้: อาคารจากหัวกระดาษ (“หมวดงาน … อาคาร D”), แต่ละงาน (F4, F6, W5, …) = 1 หมวดงาน, รายการรายชั้น/ส่วนงาน (เช่น Corridor ชั้น 4, บันได) = รายการ BOQ พร้อมค่าแรง/หน่วย (แถว ADD ติดหมายเหตุ “ADD (งานเพิ่ม)”), งานที่ไล่รายห้อง (กระเบื้องห้องน้ำ ฯลฯ) = ITEM + เพิ่มห้อง/ปริมาณต่อห้องลงตารางห้องอัตโนมัติ
- ชื่องานที่เป็น #REF! ในไฟล์ ระบบใช้ชื่อตามลำดับในตารางสรุป และติดป้าย [#REF!] ให้ตรวจ
- ยังไม่นำเข้า % Payment (Todate/Previous/This)
